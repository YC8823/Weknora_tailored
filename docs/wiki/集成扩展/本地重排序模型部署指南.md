# 本地重排序模型部署指南

本文档说明如何在 WeKnora 中接入本地自部署的重排序（Rerank）模型，适用于知识库内容需要严格数据保护、不允许调用外部 API 的场景。

## 架构说明

```
WeKnora (Docker) ──HTTP──> rerank_server_demo.py (宿主机)
                            └── BGE-Reranker 模型 (本地权重)
```

WeKnora 的 `app` 容器通过 `host.docker.internal` 访问宿主机上运行的 Python 推理服务。数据全程不出本地网络。

## 环境要求

| 组件 | 要求 |
|---|---|
| GPU | NVIDIA Blackwell (RTX 50xx) 或更早架构 |
| CUDA | 12.8 以上（Blackwell 最低要求） |
| Python | 3.10+ |
| conda | 任意版本 |
| WeKnora | Docker Compose 部署 |

---

## 第一步：创建 conda 环境

```bash
# 查看已有环境（如已有 torch 2.7+ 环境可直接克隆）
conda env list

# 方式 A：克隆已有 torch 环境（推荐，无需重新下载 torch）
conda create --name weknora-python --clone <你的torch环境名>
conda activate weknora-python
pip install fastapi uvicorn transformers pydantic

# 方式 B：全新创建（pip 有缓存时 torch 安装也很快）
conda create -n weknora-python python=3.10
conda activate weknora-python
pip install fastapi uvicorn transformers pydantic
pip install "torch>=2.7" --index-url https://download.pytorch.org/whl/cu128
```

验证 GPU 可用：

```bash
python -c "import torch; print(torch.__version__); print(torch.cuda.get_device_name(0))"
# 预期输出示例：2.7.0+cu128 / NVIDIA GeForce RTX 5060
```

---

## 第二步：下载模型权重

```bash
pip install huggingface_hub

# 下载 BGE-Reranker-v2-m3（中英双语，推荐）
huggingface-cli download BAAI/bge-reranker-v2-m3 --local-dir /data/rerank_model
```

其他可选模型：

| 模型 | 参数量 | 适合场景 |
|---|---|---|
| `BAAI/bge-reranker-v2-m3` | 568M | 中英双语，平衡性价比 |
| `BAAI/bge-reranker-large` | 560M | 英文，精度高 |
| `maidalun1020/bce-reranker-base_v1` | 279M | 中文，资源占用低 |

---

## 第三步：配置推理服务

修改项目根目录下的 `rerank_server_demo.py`，将模型路径改为实际路径：

```python
# 第 46 行
model_path = '/data/rerank_model'   # ← 改为你的实际路径
```

端口默认为 `8001`（最后一行）：

```python
uvicorn.run(app, host="0.0.0.0", port=8001)
```

如果 `8001` 被占用，修改此处端口号，后续步骤中的端口保持一致即可。

---

## 第四步：启动推理服务

```bash
conda activate weknora-python
python rerank_server_demo.py
```

验证服务正常：

```bash
curl -X POST http://localhost:8001/rerank \
  -H "Content-Type: application/json" \
  -d '{"query": "什么是机器学习", "documents": ["机器学习是AI的子领域", "今天天气不错"]}'
```

正常响应示例：

```json
{"results": [{"index": 0, "document": {"text": "机器学习是AI的子领域"}, "score": 0.97}, ...]}
```

---

## 第五步：配置 SSRF 白名单

WeKnora 内置 SSRF 安全校验会拦截对 `localhost` 和 `host.docker.internal` 的请求。需在 `.env` 中添加白名单放行：

```env
SSRF_WHITELIST=host.docker.internal
```

> **注意**：修改 `.env` 后只需重启容器，**不需要重新 build 镜像**。

```bash
docker compose down
docker compose up -d
```

---

## 第六步：在 WeKnora 中注册本地模型

进入 **模型管理 → 添加模型**，填写以下信息：

| 字段 | 填写内容 |
|---|---|
| 模型类型 | Rerank |
| 模型来源 | Remote API（远程） |
| 服务商 | 自定义（OpenAI 兼容接口） |
| 模型名称 | `bge-reranker-v2-m3-local`（任意） |
| Base URL | `http://host.docker.internal:8001` |
| API Key | 留空或任意填写（服务不校验） |
| Provider | 留空 |

点击**测试连接**，显示成功后保存。

---

## 第七步：在知识库中启用

进入目标**知识库 → 设置 → 检索配置**，将重排序模型切换为刚注册的本地模型：

| 参数 | 推荐值 | 说明 |
|---|---|---|
| Rerank 模型 | `bge-reranker-v2-m3-local` | 选择第六步注册的模型 |
| Rerank Top-K | 10 | 最终返回文档数 |
| Rerank 阈值 | 0.3 | 低于此分数的文档被过滤 |

不同知识库可独立配置，已使用远程 API 的知识库不受影响。

## Docker 化部署（可选）

项目中已预置 `docker/Dockerfile.reranker`，可将推理服务打包为 Docker 容器。模型权重通过 volume 挂载，不打包进镜像。

启用方式：取消注释 `docker-compose.yml` 中的 `reranker` service，在 `.env` 中添加：

```env
RERANKER_MODEL_PATH=/path/to/your/model_weights
```

然后：

```bash
docker compose --profile reranker up -d reranker
```

启用后，WeKnora 中注册模型的 Base URL 改为 `http://reranker:8001`（同一 Docker 网络内直接走服务名）。

## 常见问题

**测试连接失败，提示"Base URL 未通过安全校验"**
→ 第五步的 `SSRF_WHITELIST` 未生效。确认 `.env` 已修改，且执行了 `docker compose down && docker compose up -d`（不是 `--build`）。

**服务启动报"模型加载失败"**
→ 检查 `rerank_server_demo.py` 中 `model_path` 是否指向正确的本地权重目录。

**GPU 未被使用（推理很慢）**
→ 运行 `python -c "import torch; print(torch.cuda.is_available())"` 检查，若返回 `False`，说明 CUDA 环境未正确安装。

**重新 build Docker 镜像时 `pnpm install` 超时**
→ 修改 `.env` 不需要重新 build。如确实需要重建，确保构建机器网络畅通，`pagefind` 需要从外网下载二进制文件。
